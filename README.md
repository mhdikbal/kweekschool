# 🏛️ Kweekschool Historical Atlas
**Kweekschool Fort de Kock & Jejaring Nusantara**

Sebuah platform *historical storytelling* interaktif yang memetakan jejaring Kweekschool Fort de Kock dan dampaknya terhadap birokrasi serta pergerakan nasional Indonesia (1856–1915).

## 🌍 Tentang Proyek
Proyek ini mengusung pola *scrollytelling* berbasis antarmuka web, menggabungkan visualisasi data historis dan presisi narasi akademik. Dibangun dari ratusan dokumen sejarah sezaman (fokus arsip Delpher dan laporan pejabat bumiputra), website ini membedah bagaimana institusi Kweekschool yang mulanya didesain Belanda untuk melakukan rekayasa kontrol sosial dan administrasi lokal, justru menjadi medan kaderisasi yang melahirkan tokoh-tokoh revolusioner kebangsaan seperti Tan Malaka, Mohammad Hatta, dan Bagindo Dahlan Abdullah.

## ✨ Fitur Utama
- **Interactive Network Mapping**: Kanvas Peta statis namun dinamis yang menampilkan karir tokoh Pribumi dan Belanda (*1856-1912*).
- **Responsive Historical Timeline**: Lintasan perjalanan (*timeline*) waktu Kweekschool menggunakan *horizontal scroller* yang mulus.
- **Narrative Scroll Experience**: Layout editorial bergaya *modern vintage aesthetic* (lengkap dengan mask gambar, tata letak teks tajam, rona sepia *historical*).
- **Data-Driven Veracity**: Setiap pernyataan ditunjang oleh kompilasi 1.410 entri sekunder yang mengikat afiliasi pendidikan administratif kolonial.

## 🛠️ Stack Teknologi & Setup
Website dirancang murni menggunakan teknologi fundamental tanpa *framework* berat untuk mengamankan performa instan dan keabadian kode (kemudahan pemeliharaan lintas zaman):
- **Front-end**: Murni HTML5, CSS3, Vanilla JavaScript (Tanpa React, Node.js, atau pustaka eksternal pihak ketiga).
- **Deployment**: Serverless Static Web (Mudah di-deploy langsung dari GitHub Pages).

## 🚀 Instalasi & Uji Coba *Offline*
Tidak diperlukan *build pipeline* atau *compile*!
1. Unduh (`Download ZIP`) atau *clone* repositori ini.
2. Temukan dan klik ganda (`double-click`) file `index.html` dan buka via sembarang peramban modern (Chrome/Safari/Edge/Firefox).
3. Live Web-based Story dapat diakses otomatis via: **[https://mhdikbal.github.io/kweekschool](https://mhdikbal.github.io/kweekschool)**.

## 🗃️ Referensi Data & Arsip
Penelitian ini ditunjang sepenuhnya oleh arsip dokumen historis berbahasa Belanda hasil ekstraksi *Koninklijke Bibliotheek, Den Haag*:
- Laporan Inspektur Pendidikan Masyarakat Pribumi (*Tijdschrift voor Neerland's Indië*)
- Surat Keputusan Pemindahan & Kenaikan Pangkat (*Benoemingen & Mutaties*) untuk jabatan *Onderwijzer* dari koran-koran seperti *Java-bode* dan *Bataviaasch Handelsblad*
